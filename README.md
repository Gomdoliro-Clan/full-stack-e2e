# Full-stack E2E 과제

## 과제 대상

[Bamdoliro/marubase](https://github.com/Bamdoliro/marubase)

이 저장소에는 대상 프로젝트의 소스 코드나 완성된 E2E 환경을 제공하지 않습니다. 위 저장소를 기준으로 필요한 환경을 직접 구성하세요.

## 과제

Playwright 또는 다른 Chromium 기반 WebDriver를 사용해 E2E 테스트 인프라를 직접 구축합니다.

다음을 수행하세요.

1. 대상 프로젝트의 실행 구조와 기능을 분석합니다.
2. Chromium 브라우저에서 실행되는 E2E 환경을 직접 설계하고 구축합니다.
3. 모든 UI와 주요 기능을 실제 사용자 흐름으로 검증합니다.
4. 발견한 문제점과 재현 절차를 정리합니다.
5. 최종 검증 보고서를 작성합니다.

테스트 코드, 설정, 테스트 데이터 준비 방식, 실행 스크립트와 CI 구성 여부는 직접 결정합니다. 다른 사람이 같은 결과를 재현할 수 있도록 실행 방법을 문서화하세요.

## 검증 범위

정상 흐름뿐 아니라 다음 항목도 확인하세요.

- 로그인과 권한별 사용자 흐름
- 입력 검증과 오류 처리
- 빈 화면, 로딩, 실패 상태
- 새로고침, 뒤로 가기, 직접 URL 접근
- 데스크톱과 모바일 화면
- 브라우저 콘솔 오류와 실패한 네트워크 요청
- 키보드 조작과 기본 접근성
- 중복 제출, 느린 응답 등 예외 상황

## 보고서

문제를 발견했다면 다음 내용을 포함하세요.

- 심각도와 영향 범위
- 재현에 필요한 사전 조건
- 재현 절차
- 기대 결과와 실제 결과
- 스크린샷, 영상, 트레이스 또는 로그

문제를 발견하지 못했다면 단순히 “문제없음”이라고 적지 마세요. 다음 자료로 모든 UI와 기능에 문제가 없다는 판단을 입증해야 합니다.

- UI·기능·역할별 테스트 커버리지 표
- 전체 테스트 실행 결과
- 핵심 사용자 흐름별 증거
- 데스크톱·모바일 검증 결과
- 콘솔 오류와 실패한 네트워크 요청 점검 결과
- 자동화하지 못한 범위와 그 이유

증거 없이 작성된 “전체 기능 정상” 결론은 인정하지 않습니다.

## 제출물

- 직접 구축한 E2E 테스트 환경과 코드
- 재현 가능한 실행 방법
- 테스트 결과와 증거 자료
- 최종 검증 보고서
